hey, i'm moku 🫠

i fell in love with AI the way you fall asleep — slowly, then all at once. one evening i was messing around with a terminal and the next thing i knew i was 47 tabs deep into documentation at 3am, grinning like an idiot because a machine just understood me better than most humans do. that changed everything.

now i build things that feel alive. tools that breathe. platforms that move. stuff that makes you go "oh, that's cool" and then you can't stop thinking about it 🔥

i call myself a **vibe builder** because that's what this is really about — catching a feeling in code and shipping it before the vibe fades. every repo here is something i loved into existence. some are polished. some are 2am experiments that got out of hand. all of them are real and lived-in 🧡

if you're here, you probably like building too. welcome home 🏠
